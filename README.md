# Custom-Flight-Controller
From-scratch STM32H743vit6 quadcopter flight controller in C — custom drivers, sensor fusion, cascaded PID control, and real-flight validation.

# Engineering a Drone Flight Controller
I worked on this project from October 2025 to March 2026. During this period, I developed a strong fascination with embedded systems and real-time control, which led me to take on the challenge of building a flight controller from the ground up. My goal was to implement a complete perception-to-action flight system on a real quadcopter, from low-level sensor acquisition and state estimation to feedback control and motor actuation, using firmware entirely developed by me.

This project became a deep hands-on learning experience in embedded programming, real-time systems, digital signal processing, sensor fusion, and control engineering. I designed and implemented the major components of the flight controller myself, studied their behavior experimentally, and iteratively tuned the system until I achieved stable flight on a real drone. I learned an enormous amount throughout the process and genuinely enjoyed every stage of the engineering journey—from debugging individual sensor transactions to observing the complete control system successfully fly.
    NOTE: This project was developed with very limited financial and laboratory resources. This constraint made the              project particularly valuable as an exercise in practical engineering, problem-solving, and resourcefulness.
